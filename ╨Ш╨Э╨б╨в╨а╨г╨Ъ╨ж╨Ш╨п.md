# Как доделать и опубликовать сайт

Сайт полностью собран и наполнен твоими картинками: вёрстка, все тексты из кейсов, переходы между страницами, ховер-анимации на обложках, sticky-кнопка "назад", возврат на витрину в то же место скролла, кнопка "На главную". Открывай `index.html` в браузере и тестируй.

## Осталась только 1 картинка — твоё фото

В присланном архиве не было личного фото для витрины (аватарки в блоке "обо мне"). Положи файл `photo.png` (или `.jpg` — тогда поменяй расширение в `index.html`) в `images/photo.jpg`, и плейсхолдер на витрине автоматически сменится на фото.

## (Справочно) Как раскладывались картинки — на будущее

Если решишь что-то поменять или добавить новый кейс, вот структура папок, которую понимает сайт — просто сохраняй новые картинки по тому же принципу:

В твоём файле открой нужный фрейм, выбери его на канвасе и в правой панели (Export) экспортируй в PNG или JPG (лучше JPG для скриншотов интерфейса — файлы будут легче).

Экспортируй ровно то, что указано в плейсхолдере на странице — имя фрейма и путь для сохранения. Полный список ниже.

## Шаг 2. Добавь свои ссылки

В файлах `index.html`, `case-crm.html`, `case-prodoctorov.html`, `case-tbank.html` найди блоки с контактами и замени `href="#"` на реальные ссылки:
```html
<a class="contact-chip" href="#" target="_blank" rel="noopener">Telegram</a>
```
→ например `href="https://t.me/твой_ник"`. Также обнови ссылку у "Linkedin" и "CV" (можно указать прямую ссылку на PDF резюме).

## Шаг 3. Публикация на Vercel (проще всего, без кода)

1. Зарегистрируйся на [vercel.com](https://vercel.com) — можно через GitHub.
2. Если ещё нет аккаунта на [github.com](https://github.com) — создай.
3. Загрузи всю папку сайта (index.html, style.css, script.js, все case-*.html и папку images) в новый репозиторий на GitHub — проще всего через сайт GitHub: "Add file → Upload files", перетащить всю папку и нажать "Commit changes".
4. В Vercel: "Add New… → Project", выбери этот репозиторий, framework — "Other" (никаких настроек сборки не нужно, это просто статичные файлы), нажми Deploy.
5. Через минуту получишь ссылку вида `твой-проект.vercel.app` — она открывается в России без VPN.

Если позже поменяешь картинки/тексты — просто обнови файлы в GitHub-репозитории, Vercel пересоберёт сайт автоматически за секунды.

## Что уже реализовано по твоему ТЗ
- Обложки кейсов (на витрине и в блоке "Другие проекты") увеличиваются при наведении — понятно, что кликабельны.
- Чипсы с контактами меняют цвет фона при наведении (ховер уже в CSS, ссылки добавишь сам).
- Кнопка "назад" на странице кейса зафиксирована в левом верхнем углу и остаётся на месте при скролле, увеличивается при наведении.
- При нажатии "назад" ты возвращаешься на витрину ровно в то место, где остановился (позиция скролла запоминается через sessionStorage).
- В блоке "Другие проекты" обложки кейсов тоже зумятся при ховере и ведут на соответствующий кейс.
- Кнопка "На главную" в конце кейса возвращает на витрину в самое начало (наверх), в отличие от кнопки "назад".
